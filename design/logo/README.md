# Opsidian logo

**Two halves:** an O made of two arcs, a Mac and a phone each holding half and meeting. It is the first letter of the name and a quiet picture of sync, with no crystal in it.

| File               | Use                                                               |
| ------------------ | ----------------------------------------------------------------- |
| `mark.svg`         | The mark on light grounds                                         |
| `mark-on-dark.svg` | The mark on dark grounds                                          |
| `icon-mac.svg`     | Mac app icon, on Apple's 1024 px grid                             |
| `icon-iphone.svg`  | iPhone app icon, full bleed; iOS rounds the corners               |
| `menu-bar.svg`     | One-colour menu bar icon, drawn by macOS in the menu bar's colour |

Colours: violet `#8A5CF5`, lilac `#E9E1FD`, deep violet `#5B3CC4`, slate `#1E1E1E`.

After changing any of these, run `pnpm icons` to redraw the PNGs the apps use. The explorations that led here are on the "Logo — explorations" page of the Paper file.
