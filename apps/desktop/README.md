# @opsidian/desktop

Electron + React desktop notebook, styled with Tailwind and the shared theme. `components.json` is set up for shadcn/ui components under `src/components/ui`. From the repository root, use `pnpm dev:desktop`; `pnpm test:desktop` runs the native smoke test. See [what it does and does not do yet](../../docs/desktop-notebook.md).
