# @opsidian/desktop

Electron + React desktop notebook, styled with Tailwind and the shared theme. `components.json` is set up for shadcn/ui components under `src/components/ui`. From the repository root, use `pnpm dev:desktop`; `pnpm test:desktop` runs the end-to-end and crash tests against the production build. See [what it does](../../docs/desktop-notebook.md).
